# Legal and Compliance

Nuvio Desktop is configured with GPL-3.0-or-later as the project license.

## Release Blockers

- `LICENSE` exists and is included in artifacts.
- `NOTICE` exists and is included in artifacts.
- `docs/dependency-licenses.md` is complete for all third-party dependencies.
- Source availability instructions are included with binary releases.
- The app does not host, store, distribute, or bypass protections for media content.
- Logs redact stream URLs, tokens, query strings, cookies, and authorization headers.

The compliance test suite intentionally fails if required compliance files are missing.
